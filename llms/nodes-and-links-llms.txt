# Nodes & Links

> Nodes & Links is an AI-powered project management and project controls platform for construction, engineering, and large capital projects. It analyzes project schedules to surface schedule-integrity issues, delays, change, progress, risk, resource, and earned-value insights, answerable through natural-language queries. A production API is served from api.app.nodeslinks.com behind AWS API Gateway with OAuth bearer-token access; the API reference lives inside the authenticated developer portal.
